# Design decisions

These files are historical architecture/audit records. For current truth, start
at [`docs/README.md`](../README.md), [`docs/project-status.md`](../project-status.md),
and the root [`ROADMAP.md`](../../ROADMAP.md). A dated decision record does not
silently override a newer current-state document.

Why the code looks the way it does. These are working documents kept for the
record, not polished specification — most are written in Thai, and each is dated
by when the decision was made rather than continuously maintained.

| [2026-08-07 Phase 8 native broker](2026-08-07-native-broker.md) | **Accepted; Slices 1--4 integrated.** Selects an on-demand per-user broker with Windows named-pipe or macOS/Linux filesystem-UDS client IPC, a registered Chrome native-messaging adapter distributed by the Desktop companion but independent of the Desktop GUI lifecycle, and a broker-prebound private authenticated loopback backend with no storefront HTTP fallback. Connection/scope-bound sessions fail closed; Desktop and Extension cannot stop each other; global upgrade control is maintenance-only. OS peer context and package-consistency checks are explicitly not publisher attestation or protection from same-user malicious code. The owner resolved Slice 4's configuration P1 by excluding credential-requiring providers and remote TNER from the current installed Desktop/native-broker boundary: only local `thainer` is supported, `fake` is the backend allowlist solely for internal conformance, unsupported explicit selectors fail before broker connection or launch, both child seams build a fixed name-allowlisted runtime environment without querying provider/TNER credential values and pin `thainer`/`fake`, and Desktop/broker no longer snapshot remote configuration independently. The broader core, CLI, HTTP/hosted, and worker capabilities remain unchanged. Adding credential-backed providers or remote TNER to installed Desktop requires a future owner-approved ADR covering ownership, provisioning, permissions, storage, rotation, configuration identity/epoch, broker restart/reconfiguration, upgrade, uninstall, attestation, and cross-platform behavior. Installed Windows NSIS, relocated macOS app, extracted Linux DEB, and finalized outer-AppImage `--appimage-extract-and-run` plus verified warm-`AppRun` smoke remain distinct evidence classes; none substitutes for manual updater/upgrade/uninstall acceptance, and the AppImage path is not normal FUSE/double-click evidence. Slices 5--6 have not started. Extension in-page DOM boundaries remain as documented. Office remains outside broker v1 pending a separate ADR |
| [2026-08-07 AI for Thai caller authentication](2026-08-07-aift-caller-authentication.md) | Keep the hosted landing page and health public, gate every business operation behind an access-code exchange for a short-lived stateless signed `Secure`/`HttpOnly`/`SameSite=Strict` cookie, keep caller, proxy-to-core, and provider secrets separate, reject cross-site browser use, and return only minimized projections; approved for the separate `aiguard-aift` port, with GitLab push/deploy still separately owner-gated |
| [2026-08-06 session-namespaced token identity](2026-08-06-session-namespaced-token-identity.md) | Token mode combines a random 64-bit vault-generation tag with an approximately 94-bit per-token nonce, making accidental identity reuse and same-session future-token preplay computationally impractical rather than impossible. Exercised regressions keep stale or unknown exact-format tokens unchanged with only a count-only foreign warning, including under a surrogate replacement session. Neither component is a credential or session authority, HTTP v2 adds no field, and legacy tokens remain readable only at the explicit stateless prior-mapping boundary. Implemented in current source; the exact-candidate sanitize performance gate is red, its measured security trade was owner-accepted on 2026-08-06, and package/real-host acceptance remains pending |
| [2026-08-05 HTTP contract v2 privacy boundary](2026-08-05-http-contract-v2.md) | The main HTTP API cuts directly to strict v2 response projections with no v1 fallback absent a real consumer; mapping-oriented fields and raw guard/Section 26 excerpts leave the wire, offsets are half-open Unicode code points, outbound-capable operations fail closed, health separates control/data-plane authority, and server plus first-party clients migrate atomically. Implemented in current source; a dated automated packaged-backend/HTTPS-development-proxy preflight passes, while installed-client, live-provider, Office-host, and unified-package acceptance remain pending. Worker envelope v1 remains unchanged; the later AI-for-Thai caller-auth decision adapts the separate sibling's public aliases to strict contract 2 without creating an independent service-version line |
| [2026-07-29 processing receipt (มาตรา 39)](2026-07-29-processing-receipt.md) | The PDPA section 39 record is a per-run slip, not a cumulative RoPA — a register would mean retaining exactly what the in-memory vault and the request-transient hosted roundtrip path promise not to — and it is authenticated by rerunning the input and comparing digests rather than by a signature, which would prove who issued a receipt and nothing about whether it is true. `entity_id` and `score` stay outside the digest; the verifier ships in the same version as the issuer |
| [2026-07-29 Material Design 3](2026-07-29-material-design-3.md) | Every UI surface moves to MD3 — tokens, type scale, shape, state layers and elevation taken from material-web v0.192, palette generated from the brand blue with Google's own HCT implementation rather than picked by eye; no material-web component library, and the Office task pane accepts a deliberate clash with its Fluent host |
| [2026-07-29 store distribution + signing](2026-07-29-store-distribution-and-signing.md) | Distribute the installer as a direct download and carry no package-manager manifest at all (the winget/Scoop route was decided and then dropped the same day), hold the Chrome Web Store until a reviewer has an easy backend-install path, and stay unsigned — the cheapest managed signing service excludes developers based in Thailand, and since August 2024 no certificate class clears SmartScreen on first download anyway |
| [2026-07-28 tokenmind detector + AIFT port](2026-07-28-tokenmind-detector-and-aift-port.md) | tokenmind's thaillm-8b scores F2 0.951 as a detector on gold v4 — above the default rule+CRF's 0.908 on documents that carry PII, worse on the PII-free negative slice — confirming the pre-send guard must cover what the model itself sees; and the AIFT deployment moves to a separate port repo (aiguard-aift) that passed the local checklist + soak phase, deploy owner-gated |
| [2026-07-28 fine-tuned NER results](2026-07-28-finetuned-ner-results.md) | Campaign 3 verdict: the fine-tuned engine fixes blind NAME precision 0.700 → 0.922 and becomes the certified heavyweight opt-in, displacing union; CRF stays the default on latency |
